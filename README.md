# 課堂互動工具 V2.35.11｜逐層思辨理由顯示設定

## 更新內容
- 逐層思辨每一層的「我的理由」選單改為：**沿用共用設定／必填／不顯示（不用填寫）**。
- 未勾選「共用理由顯示」時，沿用共用設定的層次也會隱藏理由欄位。
- 選擇不顯示時，學生端同時隱藏「自由文字理由」和「勾選預設理由」，也不會提交先前層次的理由草稿。
- 「我還需要知道什麼？」及結束反思仍為獨立欄位，不受理由顯示設定影響。
- 不改動作答資料結構；舊活動原本儲存為「選填」的設定（`reasonRequired: false`）在新版界面解讀為「不顯示」，不會刪除舊有作答資料。未指定理由設定的舊層次仍沿用共用規則。
