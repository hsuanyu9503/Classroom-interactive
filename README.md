# 課堂互動工具 V2.19.0 — 第一波活動模組

V2.19.0 以 V2.18.0 的 Activity Module Registry 為基底，正式加入第一波三種新互動模組：**量表／立場光譜、排序／優先順序、開放文字／文字牆**。既有活動 ID、Session、Realtime、教師個別檢視與 Supabase RPC 維持相容。

## 新增模組

### 1. 量表／立場光譜 `scale-spectrum`
- 教師可設定題目、3～10 個刻度，以及左右端標籤。
- 學生以單一刻度表達目前立場。
- 教師端即時顯示已回答人數、分布、平均與中位數。
- 統計結果預設隱藏，教師按「公布結果」後才揭曉。
- 完整 Course 投影可顯示分布、平均與中位數。

### 2. 排序／優先順序 `ranking`
- 教師可設定 2～10 個排序項目。
- 學生端初始順序會打亂，可拖曳或用上下按鈕重新排序。
- 教師端即時顯示第一順位分布與各項目的平均順位。
- 個別學生檢視可查看完整排序。
- 完整 Course 投影可顯示第一順位分布與平均順位。

### 3. 開放文字／文字牆 `open-text`
- 教師可設定提問、輸入提示與 30～1000 字上限。
- 學生提交短答後，教師端形成即時文字牆。
- 教師文字牆可切換「匿名／顯示學生」；預設匿名。
- 完整 Course 投影只提供**匿名文字牆**，不會帶出學生身分。
- 個別學生檢視仍可由教師私下查看原始文字回答。

## 統計與隱私

- Slido 風即時統計沿用 V2.17 系列設計：LIVE 人數、公布／隱藏結果、動畫長條、固定配色。
- 結果隱藏時，選項維持固定順序，不再因實際票數排序而間接洩漏趨勢。
- 排序題在結果隱藏時不會用平均順位重新排序。
- 開放文字投影永遠匿名；教師自己的文字牆才可選擇顯示學生。

## 模組化架構

三個新模組皆透過 `activity-modules.js` 註冊，並分別提供：
- Editor hook：讀取、載入、驗證與分享編碼。
- Student hook：解碼、渲染與提交。
- Teacher hook：即時統計、個別檢視、課後摘要與 Course 投影資料。

後續新增量表變體、詞雲、配對、二維立場圖等活動時，可繼續沿用相同 Registry 契約。

## Supabase

本版沒有新增資料表或欄位。三個新模組的額外資料皆存入既有 `student_responses.payload` JSONB，因此：

**V2.19.0 不需要重新執行 `supabase-setup.sql`。**

## 相容性

V2.18.0 與先前版本已有的功能皆保留，包括：依據隨機排序、奇數選項等尺寸、Slido 風統計、結果預設隱藏、固定配色、個別學生檢視、理由匿名／具名切換、逐層思辨純文字選項、Course / Session / 教師接手與投影等。
