- **本版不更動任何資料庫表格或 RPC。正式網站更新只需 GitHub Pages 靜態檔。**

## SQL 整理與用途

本開發包只提供一份初始化 SQL：`sql/NEW-PROJECT-ONLY-v2.36.1-schema-unified-fixed.sql`。
此 SQL 是 v2.36.1 的歷史完整基礎結構與已整合的 v2.35.x 修補；v2.36.2 / v2.36.4 無新 SQL。
**只用在空白的新測試 Supabase 專案，不要直接在既有正式資料庫執行。**
原始 8 份 SQL（包含唯讀診斷）另置於 `sql-history/` 供舊版程式測試與追溯；該資料夾**不可直接依序執行**。日常全新測試專案只需 `sql/` 的一份整合 SQL。
此初始化 SQL 尚未在目前環境實際連接 PostgreSQL 執行；請在全新測試專案先執行並驗收。
正式環境目前仍為 v2.36.1 Schema，未更動。往後若升級至 v1.0.1，需使用 Stage 2/Stage 3 的專屬增量 SQL 與備份流程。

## 發布

- GitHub ZIP：將 ZIP 的根目錄 HTML / CSS / JS 檔部署到原本 Repo 根目錄。
- 若使用 GitHub Pages 子路徑，保持相對連結結構不變。
- 重新整理頁面並檢查教師工作台右上方 `V2.36.4`。
- 進入投影模式前，先用測試 Session 核對 0:0、1:1、3:1、1:3，並進行實際跨裝置驗收。
