# 課堂互動工具 V2.34.0｜多彩視覺與文字排版優化

基於 V2.33.1 製作的前端視覺精修版，維持原有的 8 種活動模組、Session 邏輯與 Supabase SQL 相容。

## 主要調整

- **多彩色彩系統**：課程（靛紫）、材料（琥珀）、分類（青綠）、活動（紫羅蘭）、課堂控制（湛藍）使用不同的輔助識別色；危險操作保留原來的警示色。
- **活動模組分群**：五種教學功能類別各自配色，選取模組後提供輕柔底色，讓大量選項更容易區分。
- **學生端美編**：題目卡、加入頁與課程頁加入適度的柔和漸層與多色導引線，同時保留清楚的文字閱讀區。
- **文字排版**：統一說明文字行距、深色輔助文字、標題換行與手機版按鈕文字，調整窄螢幕留白。
- **文案校正**：活動模組總數顯示由過時的「10 種模組」修正為「8 種模組」。

## 版本與部署

更新整份網站即可，`interface-polish.css` 內包含 V2.34.0 美編樣式。未修改既有活動資料結構或資料庫，若已部署 V2.32.1 的 SQL 升級檔，無須再次執行。

正式 Supabase 跨裝置同步、實機手機及投影設備仍建議部署後實測。

測試報告：`tests/QA-V2.34.0.md`。
