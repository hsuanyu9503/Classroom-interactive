# 課堂互動工具 V2.26.2 — 即時立場紅藍拉鋸與平滑動畫

V2.26.2 專注改善「即時立場拉鋸」的視覺辨識與 Realtime 動畫。**本版沒有新增 Supabase table / RPC / schema；如果已經完成 V2.26.0 的資料庫更新，不需要因為 V2.26.2 再重跑 SQL。**

## V2.26.2 調整

- **紅藍雙色拉鋸**：移除原本棕色條紋，左側支持使用藍色、右側反對使用紅色，中線保留中性分界。
- **平滑追蹤動畫**：拉鋸指示器不再每次更新瞬間跳位；Realtime 短時間連續更新時會持續追蹤最新目標，不會排隊播放舊動畫。
- **數字柔和更新**：左右人數與百分比會用短動畫過渡到新數值。
- **教師端與投影端一致**：課堂控制台、全螢幕投影、Course 投影結果共用同一套紅藍視覺。
- **極端比例修正**：0% / 100% 仍保留安全邊界，不會讓指示器跑出軌道。
- **Course 投影方向修正**：統一「左方占優往左、右方占優往右」的拉鋸方向，避免 Course 投影與教師控制台相反。
- **減少動態偏好**：系統偵測 `prefers-reduced-motion` 時會停用平滑追蹤與數字動畫。

## V2.26.1 — 介面整理與上課專注模式

V2.26.1 不新增教學模組，集中整理功能增加後的操作密度。**本版沒有新增 Supabase table / RPC / schema；如果已經完成 V2.26.0 的資料庫更新，不需要因為 V2.26.1 再重跑 SQL。**

## V2.26.1 調整

- **Course 編輯 Accordion**：Lesson 與 Node 都可收合；載入課程時只展開第一節與第一個 Node，新加入的 Lesson／Node 會自動成為目前編輯項目。收合不會影響儲存資料。
- **14 模組分類 Accordion**：五大活動分類預設只展開目前模組所在分類；切換分類與模組後會自動同步。
- **Active Session 專注模式**：有進行中的 Session 時，「今天要上什麼？」自動縮成「其他課堂操作」，需要切課／建立另一個 Session 時再展開。
- **活動編輯 Sticky 儲存列**：桌機／平板保持底部 sticky 操作列；手機只保留「儲存活動＋更多」，其餘操作按需展開。
- **小組共識統計語意**：全域「已記錄作答」改為「回傳紀錄」；小組控制台明確顯示「個人完成 X / Y」與「小組共識 A / B」。
- **既有版面順手修正**：信心程度 checkbox 固定為正常控制尺寸，避免手機版被通用 input 樣式放大。

## V2.26.0 — 第三波：小組共識

V2.26.0 延續 V2.24～V2.25 的學生彼此互動，新增第三波第三項能力：**小組共識**。這次不只加入一個活動畫面，也建立可重用的 Session 分組底層，讓後續的排序、分類或其他活動可以沿用同一套「小組／組員／共同提交」資料結構。

> **重要：V2.26.0 有 Supabase schema / RPC 更新。** 若使用跨裝置雲端 Session，升級後請到 Supabase SQL Editor **重新執行整份 `supabase-setup.sql`**。本機模式不需要資料庫更新。

## V2.26.0 新增功能

### 👥 第 14 種活動模組：小組共識

基本流程：

1. 學生先完成 **個人判斷**。
2. 教師依目前加入人數，以每組約 2～6 人自動分組。
3. 教師開放 **小組討論** 階段。
4. 學生看到自己的組別與組員，討論後共同提交 1 份答案與理由。
5. 同組任何成員都能更新同一份共識，不會產生多份互相衝突的組答案。
6. 教師端同時比較「個人判斷分布」與「小組共識分布」。
7. 教師可以查看每組成員、共識答案、理由，以及最後更新者。
8. 課後摘要會列出個人完成率、已形成共識組數與各組結果。

### 活動編輯器

可以設定：

- 核心提問。
- 2～8 個共識選項。
- 建議每組人數（2～6 人）。
- 共識理由提示。
- 理由字數上限（30～500 字）。
- 是否要求小組必填理由。

V2.26.0 第一版先以「單選共識題」完成完整教學流程；分組底層本身不綁單一題型。

### 教師控制台

新增：

- 個人作答／小組討論兩階段切換。
- 自動分組與重新分組。
- 依目前參與人數平均分配，盡量避免出現單獨 1 人的小組。
- 個人判斷即時分布。
- 小組共識即時分布。
- 每組組員與共同答案檢視。
- 重新分組時明確提醒既有小組共識將清除。

### 學生端

個人階段：

- 學生只先做自己的判斷。
- 教師尚未開放小組階段時，可以保留／更新個人答案。

小組階段：

- 顯示「第 N 組」與組員名單。
- 保留自己的個人判斷作為討論參照。
- 同組共用一份小組答案與理由。
- 任一組員提交／更新後，同組其他裝置透過 Realtime 或輪詢取得最新結果。

## 可重用的小組資料層

Supabase 新增：

- `session_groups`：每個 Session 的小組。
- `session_group_members`：學生與小組關係。
- `group_consensus_submissions`：每組共同提交結果。

新增 RPC：

- `assign_session_groups()`：教師自動分組／重新分組。
- `submit_group_consensus()`：組員提交或更新本組共同答案。

這套分組資料並不只服務 `group-consensus`，後續可以直接讓排序、分類或其他活動接上。

## 升級方式

1. 備份目前教材資料。
2. 將網站檔案更新成 V2.26.0。
3. 如果使用 Supabase，打開 SQL Editor。
4. 貼上並執行 V2.26.0 的完整 `supabase-setup.sql`。
5. 不需要先刪除既有教材、Session 或學生作答資料。

## V2.26.0 限制

- 小組共識目前先作為「單一活動 Session」使用，尚未放進完整 Course Session。
- 第一版小組答案為單選題；分組底層已可供未來其他模組沿用。
- 真正跨裝置的同步仍需設定 Supabase；未設定時可在同一瀏覽器用本機 Session 測試。
