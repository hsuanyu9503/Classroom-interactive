# 課堂互動工具 V2.34.7｜窄螢幕選項可讀性修正版

以 V2.34.6 為基礎，**只修正 CSS 排版與首頁版本標示**；沿用原本的學生端體驗、美編、8 種活動模組、Session、資料格式及 Supabase SQL。

## 沿用 V2.34.6 的修正

1. **窄螢幕課程節次編輯**：320～640px 時，節次展開、節次編號、上下移動／刪除控制排列於第一行，節次標題改用獨立滿寬的第二行，避免文字框和移動鍵相互壓住。
2. **教師端儲存操作列**：課程、分類等底部儲存列以及活動模組的操作列改回正常文流，避免 sticky 行為在中途捲動時覆蓋題目、輸入框及模組切換卡片。
3. **窄螢幕回到頂部按鈕**：640px 以下的教師備課畫面不顯示覆蓋式返回按鈕，避免覆蓋選項卡；正常捲動仍可使用。
4. **活動模組選項微溢出**：原生 radio 保留鍵盤操作與可及性，但其隱藏輸入框改為 1×1px，排除原先 5px 超出卡片邊緣的計算範圍。

## 檢查範圍與結果

- Chromium 模擬 320／390／768／1024／1280px。
- 本輪檢查教師端五個工作區與模組展開（30 組）、加入／完整課程／思辨投影頁（15 組）、10 種學生模式於 390 與 1024px（20 組），合計 **65 組前端狀態**；另測試 320px 超長選項。
- 上述測試未偵測到可見操作元件超出卡片、全頁水平溢出或未捕捉的 JavaScript 執行錯誤。
- JavaScript `node --check`、CSS 語法解析以及原有 17 項 Session 模擬整合測試通過。
- **限制**：這些是本機程式模擬／靜態排版驗證，不能替代 iPad Safari、實際 Supabase、投影機及跨裝置實測；實際資料較長的特殊情境仍須使用者驗收。
