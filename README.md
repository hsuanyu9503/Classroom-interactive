# 課堂互動工具 V2.35.7

## 本次新增：逐層思辨・全班選擇歷程

- 教師上課控制台的「逐層思辨」區段新增「全班選擇歷程」，以學生為列、層次為欄，呈現每人各層判斷。
- 選擇改變時標示「↻」與改變次數；跳過的層次顯示「—」。
- 教師頁面可選匿名編號／具名，預設匿名；投影頁面的「選擇歷程」**永遠匿名**。
- 投影僅公開教師已公布的層次；目前尚未公布的答案保持隱藏。即使教師能看到本層作答，投影畫面也不會提前顯示。
- 支援獨立 Activity Session 與 Course 中的逐層思辨節點；Course 依 `node_ref` 分離歷程。
- 以可橫向捲動的矩陣處理手機、小平板和較多層次，保留捲動位置。
- 沒有修改學生作答資料格式或 Supabase schema；須先具備 V2.35.0 Course 升級（如從舊版升級，並需套用 V2.35.6 節點唯一鍵修正）。

## 部署

將輕量版 ZIP 內的全部檔案放到 GitHub Pages 網站根目錄。特別留意新檔案 `deliberation-history.js`，需要和其他 JavaScript 同時部署。請先備份網站與課程資料。
